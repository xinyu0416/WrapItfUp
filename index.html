WrapItfUp 快速操作

訊號表 / 屬性
左側搜尋、編輯固定字級的訊號表；勾選多列後在右側批次修改。文字欄位的複製貼上只作用於文字；線條點擊選取，不再切換方向。
開啟 / 儲存
開啟可讀回原始 PNG、PDF、SVG、VBS；.v 會進入匯入預覽。圖面匯出在上方「下載 VBS」與「其他匯出」；Ctrl+S 下載完整 .wiu.json 專案；Ctrl+F 尋找、Ctrl+H 取代目前模組的訊號。本機草稿不等於下載備份；請定期儲存專案。
模組名稱
點上方名稱或 Block 中央文字直接修改。Block、RTL、匯出檔名共用同一名稱；重新命名下載檔不會改變模組名稱。
文字編輯
單擊全選；← / → 移動游標。Enter 向下、Tab 換欄，Shift 反向。Esc 取消本次編輯。
多選 / 移動
Ctrl/Cmd 點選、Shift 範圍選取；拖 ↕ 可跨左右側。Ctrl+C/X/V 複製、剪下、貼上；Delete 刪除。
分組 / 條件
選訊號後 + Group / IFDEF / IFNDEF。名稱前加 // 可停用。條件與群組分開管理。
畫布
空白處拖移，或 Space + 拖移；滾輪縮放、F 配合畫面、F5 簡報。Ctrl+Z / Ctrl+Shift+Z 復原 / 重做。

預設每次開啟為範例，請匯出保留修改。巢狀條件與 else / elsif 尚未支援；匯入器會阻擋，避免改變介面語意。
