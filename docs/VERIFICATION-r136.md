# WrapItfUp Public r136

## Top 接線

在瀏覽器開啟離線 HTML 的完整範例, 雙擊 data_link 線段, 輸入中文標籤並按 Enter. 在圖上點標籤可再次編輯. Esc 取消編輯, 復原與重做各自移除及還原標籤. 選線後按 F2, 填入現有名稱時, 欄位保留輸入並提示重名. 改用有效名稱後 Driver 和 Load 仍指向原來的兩個 instance 接腳. 下載專案, 重新開啟 HTML, 載入剛下載的檔案, 確認新的 RTL 名稱及中文標籤均保留.

新增分支標籤時, 回歸測試比對 RTL 及 org 的內容, 並檢查固定圖形與可編輯接線匯出的 VBS 內容. 測試另涵蓋同一 net 的多個分支、同一分支的多個標籤、刪除端點及清除標籤. 圖面變更可獨立復原. Windows Visio 的實際繪圖結果仍須在桌面驗證.

## Routing and delivery

The spacing preview compares clearances, foreign-net overlaps, unresolved crossings, bridge count and drawing size before applying a change. Large unlocked orthogonal designs can use separate pin escape tracks and horizontal rows through available space. The user can reject a larger canvas. Locked blocks and manually routed wires retain their existing repair constraints. Overview and comparison images render at lower detail while validation uses full geometry.

Public regression tests cover slice-aware peer navigation, retained org directives after a layout edit, orphan Empty settings, batch edits, project reload, independent instance parameters, and actual Bash receipt verification. The helper accepts arithmetic shifts in an Empty expression. A receipt for a different package with the same segment count cannot confirm the active transfer.

Verification attempts write to `runs/run-*/verification/<implementation>-<device>/attempt-*/`. The generation record remains in the run root. The tests execute the runner with controlled compiler/simulator responses for four combinations, a failed marker, a retry, and an older explicitly selected run. Only a complete line matching the configured marker qualifies as a simulation pass. The website reports generation, compilation and simulation as pending until external evidence is available.

Run `npm run release:check` from the repository root. The suite, hosted build, offline build and public-content audit are included in the release check. Company gen_top and target-environment compilation or simulation require the external tools and testbench.
