# WrapItfUp r134 verification

## Top inspection

Selecting one wire displays both endpoint roles and their instance, group and pin paths. Endpoint buttons have a minimum height of 42 CSS pixels and 14-pixel wrapping path text, independent of canvas zoom. Multiple loads offer a chooser and previous/next controls. The trace also supports inouts, assign nodes, multi-driver notices and the original return-to-view action. The normal completion banner has been removed. While routing is running or paused its controls appear in the graph toolbar. Unresolved geometry warnings remain in the footer. Save failures and pending inputs remain visible in the header.

## Child source

The child RTL panel defaults to the physical file obtained from the package source map. First use the project's stored file, then its legacy original-source or module-source fallback. Full-file preview, copy and download preserve file-level comments, original port types, inactive preprocessor branches, other modules in a shared source, implementation and line endings. Separate declaration and ordering controls remain available. A missing physical file displays a message and disables full-source export. The module sheet can still produce a separately named interface skeleton. Normal package validation and generated Top outputs are unchanged.

## Evidence

- Automated UI-handler coverage checks driver and load paths, fanout, empty endpoints, draft and layout statuses, module source preview, bytes sent to clipboard/download, and the declaration/source switch.
- A fixture with an actual procedurally assigned output, CRLF and conditional directives matched the module sheet, the company package and both mode-specific source files.
- On a local seven-child project, all seven module source files matched the company package. Thirteen design artifacts (children, normal/empty Top, org, cfg and define files) matched r132 byte-for-byte. No private design materials are included in the update.
- All 100 automated tests, the public-content audit, hosted build and offline build passed. The supplied r132 screenshots were used to locate the clipped trace and stacked status rows. Live browser layout, browser clipboard/download behavior and external gen_top or ASIC/FPGA simulation were not verified in this environment.
